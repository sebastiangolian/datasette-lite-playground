Datasette Lite playground

Test scenarios for Datasette Lite (Datasette running fully in the browser via Pyodide + a service worker). The data files below are served from this GitHub Pages site, which sends Access-Control-Allow-Origin: *, so Datasette Lite can fetch them. Each scenario opens either on lite.datasette.io or on the self-hosted copy deployed next to this page under ./lite/.

Self-hosted copy: pinned commit of simonw/datasette-lite, analytics removed. ?ref=<branch|commit> and plugins installed from GitHub do not work there (they go through a CORS proxy that only allows lite.datasette.io); PyPI versions and plugins do.
